# THE DYOR DEPARTMENT

**You did your own research. The market did its own thing.**

A satirical, useless institution dedicated to questionable conviction, over-researched entries, disappearing liquidity and the universal experience of holding the bag.

## Product principles

- No token, no wallet connection, no real-money mechanics.
- No financial advice, signals, or promises of returns.
- Interactive satire first: the visitor is part of the joke, never the target.
- Shareable results designed for Crypto Twitter.
- Clearly fictional statistics and simulator outcomes.

## First release

- Institutional-style landing page.
- Interactive DYOR Audit with a personalized case report.
- Shareable audit results.
- Responsive, accessible interface.

## Development

Run `npm install` and then `npm run dev`.

The app uses Next.js App Router, TypeScript and Tailwind CSS.

## Disclaimer

THE DYOR DEPARTMENT is an entertainment project. All scores, classifications, scenarios and simulated market events are fictional. Nothing on this site is investment advice or a representation of real market data.
